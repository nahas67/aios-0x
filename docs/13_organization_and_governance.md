## 1. System Overview & Organizational Purpose

AIOS organizes its multi-agent intelligence into a structured corporate governance hierarchy. To prevent chaotic or uncoordinated agent interactions, AIOS establishes a 5-layer organizational hierarchy, an 8-stage agent lifecycle, and a quantitative agent reputation matrix.

---

## 2. 5-Layer AI Organizational Hierarchy

The AIOS agent workforce is structured into 5 distinct operational tiers:

```
+-----------------------------------------------------------------------------------+
|                        TIER 1: AI BOARD OF DIRECTORS                              |
|           (Global Strategy, Risk Appetite, Capital Allocation Goals)             |
+-----------------------------------------------------------------------------------+
                                          |
                                          v
+-----------------------------------------------------------------------------------+

|             (Executive Orchestration, Cross-Community Coordination)               |
+-----------------------------------------------------------------------------------+
                                          |
                                          v
+-----------------------------------------------------------------------------------+

+-----------------------------------------------------------------------------------+
                                          |
                                          v
+-----------------------------------------------------------------------------------+
|                         TIER 4: TEAM LEADERS / MODERATORS                         |
|   (Debate Moderator, Risk Profiler, Execution Manager, Memory Indexer)           |
+-----------------------------------------------------------------------------------+
                                          |
                                          v
+-----------------------------------------------------------------------------------+
|                        TIER 5: SPECIALIST WORKER AGENTS                           |
|  (Bull Agent, Bear Agent, Quant Agent, Fact Checker, Order Router, etc.)          |
+-----------------------------------------------------------------------------------+
```

### 2.1 Tier Definitions & Responsibilities
- **Tier 1: AI Board of Directors** — High-level governance setting target returns, maximum allowable drawdown limits, portfolio risk appetite, and capital allocation budgets.
- **Tier 2: CEO Agent** — Executive orchestrator ensuring macro workflow alignment across all communities and monitoring overall operational health.
- **Tier 3: Department Leaders (Community Heads C1–C9)** — Manage domain-specific responsibilities (e.g. C1 Data, C2 Research, C3 Verification, C9 Portfolio Intelligence).
- **Tier 4: Team Leaders & Debate Moderators** — Coordinate multi-agent debate sessions, aggregate worker outputs, and enforce quality control within communities.
- **Tier 5: Specialist Worker Agents** — Highly specialized, single-task agents (e.g., Bull Thesis Agent, Fact Checker Agent, Slippage Calculator Agent).

## 3. 8-Stage Agent Lifecycle

Every agent variant created within AIOS progresses through an explicit 8-stage lifecycle governed by Community 8 (Evolution Mechanisms):

```
[1. Birth] -> [2. Training] -> [3. Paper Trading] -> [4. Evaluation]
                                                            |
                                                   [PASS] /   \ [FAIL]
                                                         v     v
[8. Archive] <- [7. Retirement] <- [6. Live Trading] <- [5. Promotion]
```

### 3.1 Lifecycle Stage Details
1. **Birth**: Agent prompt specification and initial parameters are generated by Community 8 (Evolution) or system configuration.
2. **Training**: Agent is calibrated against historical training datasets and domain prompt templates.
3. **Paper Trading**: Agent operates in zero-capital-risk simulation within the Continuous Training Environment for a minimum 14-day validation window.
4. **Evaluation**: Quantitative audit of agent performance against benchmark criteria (Sharpe > 1.5, Win Rate > 55%, Max Drawdown < 10%).
5. **Promotion**: Passing agents are approved for candidate deployment and granted capital allocation weights by Community 9 (Portfolio Intelligence).
6. **Live Trading**: Active execution on live or high-fidelity paper trading routes under continuous rolling observation.
7. **Retirement**: Triggered when rolling performance falls below benchmark thresholds for two consecutive review periods or alpha decay is detected.
8. **Archive**: Agent prompt, weights, and complete operational history are permanently stored in Community 7 (Memory Architecture) for post-mortem learning.

## 4. Agent Reputation Matrix

To ensure meritocratic delegation and dynamic weighting, AIOS maintains a quantitative **Reputation Score** ($R_{agent} \in [0.0, 100.0]$) for every active agent.

### 4.1 Scoring Formula

$$R_{agent} = 0.30 \cdot W + 0.25 \cdot A + 0.20 \cdot V + 0.15 \cdot Q + 0.05 \cdot L + 0.05 \cdot R$$

| Metric Component | Weight | Definition & Measurement |
| :--- | :---: | :--- |
| **Win Rate ($W$)** | **30%** | Realized trade win percentage resulting from agent's recommendations. |
| **Accuracy ($A$)** | **25%** | Prediction accuracy score (directional and target price precision from C6). |
| **Verification Score ($V$)** | **20%** | Percentage of agent's hypotheses passing C3 verification without hallucination flags. |
| **Reasoning Quality ($Q$)** | **15%** | Post-mortem score evaluating logical consistency and counter-argument depth. |
| **Latency ($L$)** | **5%** | Execution/response time score relative to community SLA. |
| **Reliability ($R$)** | **5%** | Uptime and zero-exception completion rate. |

### 4.2 Governance Impact of Reputation Score
- **High Reputation ($R \ge 85.0$)**: Agent hypotheses receive priority routing in Community 2 debates; higher allocation weighting in Community 9.
- **Moderate Reputation ($65.0 \le R < 85.0$)**: Standard operational weighting.
- **Low Reputation ($R < 65.0$)**: Agent enters probationary review. Community 8 issues prompt optimizations.
- **Critical Reputation ($R < 50.0$)**: Agent is automatically demoted or retired.
